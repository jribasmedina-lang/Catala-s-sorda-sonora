# La màquina de les esses

Aplicació web estàtica per practicar la essa sorda i la essa sonora (5è de Primària).

## Publicar a GitHub Pages
1. Crea un repositori nou a GitHub, per exemple `catala-essa`.
2. Puja tots els fitxers d'aquesta carpeta a l'arrel del repositori.
3. Ves a **Settings → Pages**.
4. A **Build and deployment**, tria **Deploy from a branch**.
5. Selecciona la branca `main` i la carpeta `/ (root)`, i desa.
6. Quan GitHub acabi la publicació, l'adreça serà `https://EL_TEU_USUARI.github.io/catala-essa/`.

## Afegir al mòbil
- Android (Chrome): obre l'adreça publicada, menú ⋮ → **Instal·la l'aplicació** o **Afegeix a la pantalla d'inici**.
- iPhone (Safari): obre l'adreça, botó Compartir → **Afegir a la pantalla d'inici**.

L'aplicació incorpora manifest i memòria cau bàsica per tornar a obrir-la sense connexió després de la primera visita.
